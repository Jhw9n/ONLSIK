# 대표 음식과 검색 보완

## 데이터

`ONEULSIK/Resource/Data/FoodReferences.json`은 공공 식품 DB 위에 놓는 대표 음식 43종과 정규화된 이름 76개의 목록입니다. 대표 음식명·별칭·원본 식품코드·원본명·기준단위·출처·기준일을 관리합니다. 영양값은 새로 만들지 않고 SQLite 원본 레코드에서 가져옵니다.

- 순찌·부찌·된찌·김찌·공기밥·공깃밥 등 일상 표현을 검색할 수 있습니다.
- 원본 레코드를 지정해 같은 이름의 검색 결과가 최저 열량 위주로 선택되지 않도록 합니다. 그 외 중복은 일반/급식 우선순위, 최신 기준일, 식품코드 순으로 정리합니다.
- 기본 순두부찌개는 순두부찌개 모듬, 된장국은 된장국 두부, 고등어구이는 고등어구이 석쇠를 참조합니다. 실제 식당 조리법과 동일하다는 보장은 없습니다.
- g과 mL는 별도로 유지합니다. 대표 분량은 기존 `FoodPortion`의 출처 있는 자료를 사용합니다.
- 선택적인 `estimatedPortions` 필드는 향후 식사 분석에서 사용할 기본 추정량 메타데이터입니다. 미소된장국 200g, 고등어구이 250g은 실측·검증된 제공량이 아닙니다. 이번 직접 검색 화면에 이 메타데이터를 자동 적용하지 않습니다.

## 검색 규칙

별칭 및 띄어쓰기 정규화, 원본 대표명, 재료와 요리 이름의 어순 분리로 후보를 찾습니다. 결과가 없으면 대표 목록의 4글자 이상 이름에서 편집거리 1인 후보를 최대 3개 찾습니다. 유사 철자는 정답으로 자동 선택하지 않고 사용자가 검색 결과를 확인합니다. 짧은 김밥/김밤 등은 이 방식으로 교정하지 않습니다.

원본 DB와 기존 기록을 변경하지 않고 검색 결과의 중복 및 우선순위만 정리합니다. 자연어 식사 분석·추가 질문·AI 화면은 별도 작업 범위입니다.

## 유지보수와 검증

`python3 Scripts/validate_food_references.py`로 참조 코드의 존재, 이름·단위·출처·기준일 일치, 일반 조리 음식 여부, 영양값의 유한성·비음수, 별칭 충돌, 기본 추정량 형식을 확인합니다. 영양학적 정확도를 인증하는 검증은 아닙니다.
